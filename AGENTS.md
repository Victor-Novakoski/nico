# Nico

PWA de gastos: a pessoa fala ou escreve os gastos, a IA monta a lista de lançamentos para conferir, e o app mostra a fatura de cada cartão e quanto cada pessoa deve. React + Vite + TypeScript no app, FastAPI em Python no backend, Postgres no Neon.

- Antes de uma tarefa, leia `docs/INDEX.md` e abra só o que ela pede.
- As regras gerais, "Git e PR" e "Segurança e custo" estão no `CLAUDE.md` da raiz e valem para qualquer IA.
- Comandos: ainda não há código; quando houver, ficam no `CLAUDE.md`.
